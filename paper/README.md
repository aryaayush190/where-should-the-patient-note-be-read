# Paper

| Path | Content |
|---|---|
| `TELMED2027_paper.pdf` | The submitted paper (6 pages, IEEE conference format) |
| `generated/numbers.tex` | Every number printed in the paper, generated by `experiments/paper_numbers.py` |
| `figures/make_figures.py` | Draws Figs. 1–3 (and an unused Fig. 4) from `generated/numbers.tex` as vector PDF and 600-dpi PNG |
| `paper_content.py` | The paper's text; numbers are inserted from `generated/numbers.tex` (`{m:name}`), citations are numbered by first use |
| `build_ieee_docx.py` | Builds the Word manuscript in the IEEE US Letter template: `python paper/build_ieee_docx.py out.docx` |
| `docx_to_pdf.ps1` | Exports the Word file to PDF with Microsoft Word (Windows): `powershell -File paper/docx_to_pdf.ps1 -Name out` |
| `ieee_template_src/` | IEEE conference template, re-saved by Word in transitional format so python-docx can read it |

Rebuilding requires `pip install -r requirements-paper.txt`; the PDF export requires Microsoft Word.
