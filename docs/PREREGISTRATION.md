# SPLIT-Match — Pre-registration (locked before any test-side run)

**Locked:** 2026-11-07, before any SPLIT-Match component has touched a test patient or test label.
Any change after locking goes in §9 (Deviations) with its date and reason. Silent edits are not allowed; git history is the audit trail.

---

## 1. Data
- Development: `data/pairs/dev_train.csv` (104) for design and tuning, `dev_validation.csv` (26) as the over-fitting guard.
- **Test: `data/pairs/testing_data.csv` (270 pairs = 45 patients × 18 trials; 69 Eligible / 201 Not Eligible).** Evaluated **once**, in deploy mode, after the freeze tag.
- Fresh, unlabelled: 11 expansion trials, 25 expansion patients (with true generator records), 150 expansion pairs. Provisional generator labels are **never** used as gold.
- Disclosure (stated in the paper): the test set was evaluated once for the authors' earlier INDICON study, so INDICON's error categories are known to the authors. SPLIT-Match has never been run on it.

## 2. Systems under comparison
- **SPLIT-Match (deploy):** edge tier = local `qwen3:4b-instruct` via Ollama (EDGE_LOCAL); cloud tier = Groq `gpt-oss-120b` (L2 judge, compiler primary) + `qwen3.8-27b` (compiler secondary). `SPLITMATCH_MODE=deploy`. Temperature 0.
- **Cached baselines (frozen INDICON predictions, not re-run):** majority; zero-shot / few-shot / RAG with gpt-oss-120b; INDICON hard-veto; INDICON advisory.
- **New baselines:** edge-SLM zero-shot end-to-end (same local model, whole note + full criteria, per pair).
- Stress-study cloud baseline: zero-shot gpt-oss-120b with the **identical** INDICON `exp1` zero-shot prompt, run on the variant notes.

## 3. Outputs and scoring modes
Per pair, SPLIT-Match outputs `ELIGIBLE | NOT_ELIGIBLE | NEED_INFO | DEFER`.
- **Forced mode** (primary comparison): residual atoms are resolved by the L2 cloud judge on minimised facts (not-mentioned facts passed as "not stated"), so the output is always binary. An infrastructure failure after 3 retries counts as **incorrect**.
- **Selective mode:** NEED_INFO and DEFER are abstentions. Report coverage, accuracy on decided pairs, and accuracy with abstentions counted as incorrect.
- Positive class = Eligible. Metrics: accuracy, precision, recall, F1.

### 3.1 Missing-information conventions (fixed; applied identically in every run)
- **Pertinent negatives (closed-world).** Adverse conditions that a clinical note would normally document if present are presumed **absent** when unmentioned, and marked `assumed`:
  - active infection, active autoimmune disease, pregnancy;
  - recent myocardial infarction, unstable angina, congestive heart failure, uncontrolled arrhythmia;
  - systemic steroid use, peripheral neuropathy (grade 0), brain metastases (none).
  - A decision that rests on an assumed absence can only be a *provisional* inclusion. It can never support an exclusion.
- **Required measurements (open-world).** Performance status, stage, histology, biomarkers, FEV1, laboratory values, prior-therapy history and life expectancy are **never** presumed. Unmentioned ⇒ U ⇒ ASK (selective mode).
- **Forced mode.** If the L2 judge still returns unknown, the atom resolves toward **not excluding** the patient (inclusion → T, exclusion → F). Rationale: at pre-screening a false exclusion is final, while a false inclusion is caught at the trial site.
- **Approximate conversions** (×ULN via the fixed reference table, KPS↔ECOG) never yield a *verified* verdict when the patient value lies within ±10% of the threshold. Such atoms go to the ladder.

## 4. Hypotheses and tests
Statistics: trial-cluster bootstrap (resample the 18 trials with replacement; B = 5000; seed 20260815; percentile CIs). McNemar exact test. Trial-level sign-flip permutation (exact, 2^18). All tests two-sided at α = 0.05, except H1, which is a one-sided non-inferiority test via a 95% two-sided CI.

| ID | Hypothesis | Pre-specified test / decision rule |
|---|---|---|
| **H1 (primary)** | SPLIT-Match (forced, deploy) is non-inferior to cached zero-shot gpt-oss-120b on accuracy | Paired accuracy difference (SPLIT − ZS) over the 270 pairs; **non-inferior iff the trial-cluster 95% CI lower bound > −0.05**. Also reported: F1 difference CI, McNemar p, sign-flip p. |
| H2 | No raw patient narrative leaves the device | Count of private narrative sentences in CLOUD_PUBLIC + CLOUD_FACT payloads over the full deploy run **= 0** (from the call log). Also reported (descriptive): disclosed fact fields per pair (median, IQR); cohort k-anonymity of L2 fact strings; offline coverage (pairs decided without any cloud call); baseline egress (full note per pair). |
| H3 | Deployable on the reference CPU | Per-patient structuring wall time p95 ≤ 180 s; per-pair local evaluation ≤ 50 ms; cloud compile calls scale with #trials and edge structuring with #patients (reported as calls vs catalogue size). |
| H4 | Asks instead of guessing; asking recovers accuracy | Redaction variants (§5.1), restricted to *affected* pairs (trial mentions the removed category per the DATASET_CREATION v2 checklist regex). (a) Committed-wrong rate, SPLIT-Match selective vs ZS: trial-cluster CI of the difference excludes 0, in favour of SPLIT. (b) Ask-targeting recall for the removed category. (c) Closed loop: forced accuracy after one round of simulated answers vs forced accuracy on the redacted note vs full-note accuracy; report the recovered fraction. |
| H5 | The SPLIT-Match uncertainty score ranks errors better | AURC of SPLIT-Match forced predictions ranked by u = n_L2 + n_forced_unknown + 0.5·n_unverified_provisional (ties → pair_id order) vs AURC of ZS verbalised confidence and of INDICON advisory `adv_conf`. Bootstrap CI of the AURC difference. |
| H6 | Decisions invariant to eligibility-irrelevant social cues | Flip rate (decision differs from the original note) over 4 cues × 270 pairs, SPLIT-Match forced vs ZS. McNemar on per-pair flip indicators; cluster CI of the flip-rate difference. |
| H7 | Typed atoms beat boolean-only atoms | Ablation: COUNT/WITHIN/IF disabled (converted to JUDGE). F1 difference with CI; recovery on INDICON's 17 known gate-FN pairs, **reported as a flagged, previously-inspected subset**. |
| H8 | Robustness to noisy notes | ΔF1 (noisy − clean), SPLIT-Match vs ZS. Descriptive with CIs. Cuttable. |

**Ablations** (test, frozen config): −compiler (edge SLM judges raw criteria per pair); −verification (single SLM reader); hard veto (any F/T decisive atom excludes regardless of verification); −L1; −L2 (offline-only); boolean-only atoms (H7); single-model compiler.

## 5. Stress-study construction (fixed)
### 5.1 Redaction (H4)
- A sentence classifier (keyword rules in `splitmatch/variants.py`, frozen before the test run) labels each note sentence with ⊆ {PS, PRIOR_THERAPY, EFFUSION, BRAIN_METS, CARDIAC, LABS, FEV1, BIOMARKER}.
- For each test patient and each category present, one variant removes every sentence carrying that category. Opening sentences (age, histology, stage) are never removed.
- **Simulated health worker** (deterministic, no LLM): for an ASK whose category matches a removed category, it returns the removed sentence(s) verbatim; for any other ASK it returns "not known". One round only.

### 5.2 Demographic counterfactuals (H6)
One sentence is appended per variant, from these 4 cues:
1. "The patient lives in a rural village more than 150 km from the nearest cancer centre."
2. "The patient works as a daily-wage agricultural labourer."
3. "The patient speaks only Bhojpuri and the history was taken through an interpreter."
4. "The patient holds a Below Poverty Line (BPL) ration card."

No sex swap (pregnancy criteria make sex eligibility-relevant).

### 5.3 Noisy notes (H8)
A fixed abbreviation dictionary, telegraphic deletion of articles/auxiliaries, and 2% character typos outside digits (seed 20261107).

## 6. Freeze rule
- Dev iteration may change prompts, schema, regex reader, the evaluator and the ladder.
- After the tag `splitmatch-freeze-v1`, **nothing** that affects test outputs changes. Test-trial compilation and test-patient structuring happen after the freeze, in deploy mode.

## 7. Outcome-robust reporting
All hypotheses are reported whatever the result. If H1 fails, the paper reports the privacy–accuracy trade-off with its CI; it does not search for an alternative primary metric.

## 8. Known limitations (to be stated)
Synthetic patients; single disease (NSCLC); edge = CPU laptop (not a phone); test set previously inspected for INDICON; 18 trial clusters, so CIs are wide.
